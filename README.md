# Верещагин Виталий Николаевич ИТ-3 Лабораторная №1

**Вариант 2.** Задания: 1 — задачи 6–10, 2 — задачи 6–10, 3 — задачи 6–10, 4 — задачи 6–10.

Всё решение — один класс `Main` ([Main.java](Main.java)), каждая задача — отдельный метод. Главный метод `main` показывает меню «задание → задача», после выбора запрашивает исходные данные и выводит результат. Весь ввод проверяется: нецелое число, число вне допустимого диапазона, не один символ вместо `char` — программа сообщает об ошибке и спрашивает заново (вспомогательные private-методы `readInt`, `readIntInRange`, `readChar`, `readWord`, `readArray`).

В условиях встречается тип `bool`; в Java используется `boolean`.

# Задание 1

## Задача 6. Большая буква
## Текст задачи
Сигнатура: `public boolean isUpperCase(char x);`. Метод принимает символ `x` и возвращает `true`, если это большая буква в диапазоне от 'A' до 'Z'.
Пример 1: x='D' → true. Пример 2: x='q' → false.
### Алгоритм решения
Символы в Java — числа (коды), поэтому их можно сравнивать операторами `>=` и `<=`. Возвращаем значение выражения `x >= 'A' && x <= 'Z'`. Ветвление не нужно — условие уже является `boolean`.

## Задача 7. Диапазон
### Текст задачи
Сигнатура: `public boolean isInRange(int a, int b, int num);`. Метод принимает границы диапазона `a` и `b` и возвращает `true`, если `num` входит в диапазон (включая границы). Заранее неизвестно, какая из границ больше.
Пример 1: a=5, b=1, num=3 → true. Пример 2: a=2, b=15, num=33 → false.
### Алгоритм решения
Находим меньшую границу `Math.min(a, b)` и большую `Math.max(a, b)`. Число входит в диапазон, если `num >= min && num <= max`. Так порядок `a` и `b` не важен.

## Задача 8. Делитель
### Текст задачи
Сигнатура: `public boolean isDivisor(int a, int b);`. Метод возвращает `true`, если любое из принятых чисел делит другое нацело.
Пример 1: a=3, b=6 → true. Пример 2: a=2, b=15 → false.
### Алгоритм решения
Проверяем два случая: `a % b == 0` («b делит a») или `b % a == 0` («a делит b»). Чтобы не получить `ArithmeticException` при делении на ноль, перед каждой проверкой убеждаемся, что делитель не равен 0 (`b != 0`, `a != 0`). Результат — логическое «или» двух проверок.

## Задача 9. Равенство
### Текст задачи
Сигнатура: `public boolean isEqual(int a, int b, int c);`. Метод возвращает `true`, если все три полученных числа равны.
Пример 1: a=3, b=3, c=3 → true. Пример 2: a=2, b=15, c=2 → false.
### Алгоритм решения
Три числа равны, если равны первое со вторым и второе с третьим: `a == b && b == c`.

## Задача 10. Многократный вызов
### Текст задачи
Сигнатура: `public int lastNumSum(int a, int b);`. Метод считает сумму цифр двух чисел из разряда единиц. С его помощью нужно последовательно сложить пять чисел и вывести результат на экран, используя минимально возможное количество вспомогательных переменных.
Пример: 5+11 это 6; 6+123 это 9; 9+14 это 13; 13+1 это 4; Итого 4.
### Алгоритм решения
Последняя цифра числа — остаток от деления на 10 (`% 10`). Метод возвращает `abs(a % 10) + abs(b % 10)` (модуль — чтобы корректно работать с отрицательными числами). В демонстрации используется одна переменная-накопитель `result`: считываем первое число в `result`, затем в цикле четыре раза читаем очередное число, вычисляем `result = lastNumSum(result, next)` и печатаем шаг. После цикла выводим «Итого `result`».

# Задание 2

## Задача 6. Тройная сумма
### Текст задачи
Сигнатура: `public boolean sum3(int x, int y, int z);`. Метод возвращает `true`, если два любых числа из трёх можно сложить так, чтобы получить третье.
Пример 1: x=5, y=7, z=2 → true. Пример 2: x=8, y=-1, z=4 → false.
### Алгоритм решения
Существует три варианта выбора «третьего» числа: `x + y == z`, `x + z == y`, `y + z == x`. Метод возвращает «или» этих трёх условий.

## Задача 7. Двойная сумма
### Текст задачи
Сигнатура: `public int sum2(int x, int y);`. Метод возвращает сумму `x` и `y`. Однако если сумма попадает в диапазон от 10 до 19, нужно вернуть 20.
Пример 1: x=5, y=7 → 20. Пример 2: x=8, y=-1 → 7.
### Алгоритм решения
Вычисляем `sum = x + y`. Если `sum >= 10 && sum <= 19` — возвращаем 20, иначе — `sum`.

## Задача 8. Возраст
### Текст задачи
Сигнатура: `public String age(int x);`. Метод возвращает строку: число `x`, затем слово «год» (если число заканчивается на 1, кроме 11), «года» (если заканчивается на 2, 3, 4, кроме 12, 13, 14), «лет» — во всех остальных случаях.
Примеры: x=5 → «5 лет»; x=31 → «31 год»; x=44 → «44 года».
### Алгоритм решения
Берём модуль числа `n`, находим `last = n % 10` и `lastTwo = n % 100`. Цепочка `if / else if / else`: 
1. если `lastTwo` от 11 до 14 — «лет» (исключения 11–14; проверка по двум последним цифрам корректно работает и для 111, 112 и т. д.);
2. иначе если `last == 1` — «год»;
3. иначе если `last` от 2 до 4 — «года»;
4. иначе — «лет».

Возвращаем `x + " " + слово`. Порядок проверок важен: исключения проверяются первыми.

## Задача 9. День недели
### Текст задачи
Сигнатура: `public String day(int x);`. Метод принимает число `x` (1 — понедельник, 7 — воскресенье) и возвращает название дня. Если число не от 1 до 7 — текст «это не день недели». Вместо `if` использовать `switch`.
Пример: x=5 → «пятница».
### Алгоритм решения
Оператор `switch (x)` с ветками `case 1 … case 7`, в каждой `return` соответствующего названия; ветка `default` возвращает «это не день недели».

## Задача 10. Вывод дней недели
### Текст задачи
Сигнатура: `public void printDays(String x);`. Метод принимает название дня недели и выводит на экран этот день и все последующие до конца недели (первый день — понедельник, последний — воскресенье). Если передан не день — выводится «это не день недели». Вместо `if` использовать `switch`.
Пример 1: x=«четверг» → четверг, пятница, суббота, воскресенье. Пример 2: x=«чг» → «это не день недели».
### Алгоритм решения
Используем `switch` по строке (приведённой к нижнему регистру и без пробелов по краям) и намеренно **не ставим `break`** между ветками дней: после совпадения с нужной веткой выполнение «проваливается» дальше и печатает все следующие дни. `break` стоит только после «воскресенья». Ветка `default` печатает «это не день недели».

# Задание 3

## Задача 6. Одинаковость
### Текст задачи
Сигнатура: `public boolean equalNum(int x);`. Метод возвращает `true`, если все знаки числа одинаковы, и `false` в ином случае.
Пример 1: x=1111 → true. Пример 2: x=1211 → false.
### Алгоритм решения
Работаем с модулем числа (в `long`, чтобы не было проблем с `Integer.MIN_VALUE`). Запоминаем последнюю цифру `last = n % 10`. В цикле `while (n > 0)` сравниваем текущую последнюю цифру `n % 10` с `last`; при несовпадении сразу возвращаем `false`; затем отбрасываем цифру `n /= 10`. Если цикл завершился без несовпадений — возвращаем `true`.

## Задача 7. Квадрат
### Текст задачи
Сигнатура: `public void square(int x);`. Метод выводит на экран квадрат из символов `*` размером `x` (x символов в ряду и x рядов).
Пример: x=4 → четыре строки `****`.
### Алгоритм решения
Два вложенных цикла `for`: внешний (`x` раз) — строки, внутренний (`x` раз) — печать `*` в строке; после внутреннего цикла — перевод строки.

## Задача 8. Левый треугольник
### Текст задачи
Сигнатура: `public void leftTriangle(int x);`. Метод выводит треугольник из `*` высотой `x`, где количество символов в ряду равно номеру строки.
Пример: x=4 → `*`, `**`, `***`, `****`.
### Алгоритм решения
Внешний цикл по номеру строки `i` от 1 до `x`; внутренний цикл печатает `i` символов `*`; затем перевод строки.

## Задача 9. Правый треугольник
### Текст задачи
Сигнатура: `public void rightTriangle(int x);`. Метод выводит треугольник из `*` высотой `x`, выровненный по правому краю: перед звёздочками выводится нужное число пробелов.
Пример: x=4 → `   *`, `  **`, ` ***`, `****`.
### Алгоритм решения
Для строки `i` (от 1 до `x`) сначала печатаем `x - i` пробелов, затем `i` звёздочек, затем перевод строки. Общая ширина каждой строки — `x`.

## Задача 10. Угадайка
### Текст задачи
Сигнатура: `public void guessGame();`. Метод генерирует случайное число от 0 до 9, считывает с консоли число пользователя и сообщает, угадал ли он. Метод работает, пока число не угадано; затем выводится количество потребовавшихся попыток.
### Алгоритм решения
1. `secret = new Random().nextInt(10)`, счётчик `attempts = 0`.
2. В цикле `while (true)`: читаем число с проверкой (целое и в диапазоне 0..9), увеличиваем `attempts`.
3. Если число совпало с `secret` — сообщаем «Вы угадали!» и выходим из цикла по `break`; иначе — «Вы не угадали» и новая попытка.
4. После цикла выводим «Вы отгадали число за N попыток» с правильным окончанием (вспомогательный private-метод `attemptsWord`: попытку / попытки / попыток).

# Задание 4

## Задача 6. Реверс
### Текст задачи
Сигнатура: `public void reverse(int[] arr);`. Метод изменяет массив `arr` так, чтобы он был записан задом наперёд.
Пример: [1,2,3,4,5] → [5,4,3,2,1].
### Алгоритм решения
Идём `i` от 0 до `length / 2` (не включая) и меняем местами `arr[i]` и `arr[length - 1 - i]` через временную переменную. Средний элемент при нечётной длине остаётся на месте. Новый массив не создаётся.

## Задача 7. Возвратный реверс
### Текст задачи
Сигнатура: `public int[] reverseBack(int[] arr);`. Метод возвращает новый массив, в котором значения `arr` записаны задом наперёд.
Пример: [1,2,3,4,5] → [5,4,3,2,1].
### Алгоритм решения
Создаём массив `result` той же длины. Для каждого `i` записываем `result[i] = arr[length - 1 - i]`. Исходный массив не меняется.

## Задача 8. Объединение
### Текст задачи
Сигнатура: `public int[] concat(int[] arr1, int[] arr2);`. Метод возвращает новый массив: сначала элементы `arr1`, затем `arr2`.
Пример: [1,2,3] и [7,8,9] → [1,2,3,7,8,9].
### Алгоритм решения
Создаём массив длиной `arr1.length + arr2.length`. Первым циклом копируем `arr1` в начало, вторым — `arr2` со смещением `arr1.length`.

## Задача 9. Все вхождения
### Текст задачи
Сигнатура: `public int[] findAll(int[] arr, int x);`. Метод возвращает новый массив с индексами всех вхождений числа `x` в `arr`.
Пример: arr=[1,2,3,8,2,2,9], x=2 → [1,4,5].
### Алгоритм решения
Длина результата заранее неизвестна, поэтому проход в два этапа: (1) считаем, сколько раз `x` встречается в массиве; (2) создаём массив такой длины и вторым проходом записываем в него индексы совпавших элементов. Если вхождений нет — вернётся пустой массив.

## Задача 10. Удалить негатив
### Текст задачи
Сигнатура: `public int[] deleteNegative(int[] arr);`. Метод возвращает новый массив со всеми элементами `arr`, кроме отрицательных.
Пример: [1,2,-3,4,-2,2,-5] → [1,2,4,2].
### Алгоритм решения
Аналогично задаче 9: первым проходом считаем неотрицательные элементы, создаём массив нужной длины, вторым проходом копируем в него элементы `>= 0`, сохраняя порядок.
